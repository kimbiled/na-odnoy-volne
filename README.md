# На одной волне

Личное приглашение на концерт. React 19 + Vite + Tailwind CSS 4, без сервера и API-ключей.

```sh
npm install
npm run dev
```

Vite показывает адрес в сети: его можно открыть с телефона, подключённого к тому же Wi-Fi.

## Персонализация

Все тексты и детали события находятся в `src/config.js`. Пока не указаны исполнитель, место, время, месяц и год, сайт не отображает вымышленные детали.

Два видео положить в `public/videos/` и указать пути:

```js
meetingVideo: '/videos/our-story.mp4',
invitationVideo: '/videos/your-invitation.mp4',
```

Рекомендуемый формат: MP4 (H.264, AAC), сжатый для мобильного интернета. Видеоплеер поддерживает вертикальные и горизонтальные ролики, `playsInline` и штатные controls. До подключения видео показывается оформленная заглушка. При ошибке загрузки можно повторить попытку.

## Сценарий

1. Интерактивная пластинка и первая глава доступны сразу.
2. Ритм-игра открывает вторую главу и личное приглашение: поймать 10 из 16 нот. Есть пауза и повторная попытка. При сворачивании вкладки игра автоматически останавливается.
3. Режим «Без спешки» позволяет сыграть мелодию без таймера.
4. Приглашение и ответ сохраняются в localStorage этого браузера. Кнопка ответа открывает системное меню отправки; на компьютере копирует текст. Сам по себе клик «Да» не отправляет сообщение организатору.
5. Приглашение можно скачать в SVG или сохранить через меню телефона.

Это романтический сценарий, а не механизм ограничения доступа: клиентский код не защищает видео от прямого открытия по URL.

## Музыка в игре

В `src/config.js` → `gameTrack` подключён официальный аудиофрагмент «like JENNIE» из Apple Music. Запись проигрывается по внешней ссылке только после нажатия «Давай сыграем» / «Начать мелодию». Пауза, выключение звука, сворачивание вкладки, завершение партии и закрытие окна останавливают музыку. Повторная попытка начинает фрагмент заново. При ошибке сети игра продолжает работать со звуками клавиш. На странице есть ссылка на источник.

Для собственного аудиофайла можно заменить `gameTrack.source` на путь из `public/audio/`.

## Проверка и сборка

```sh
npm test
npm run build
npm run test:e2e
```

Для браузерных тестов используется установленный Google Chrome (по умолчанию macOS) или переменная `CHROME_PATH`. Проверяются мобильная верстка, оба режима игры, пауза, открытие приглашения, сохранение прогресса и модальные окна. Собранный статический сайт находится в `dist/`.
