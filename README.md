# На одной волне

Личное приглашение на концерт. React 19 + Vite + Tailwind CSS 4, без сервера и API-ключей.

```sh
npm install
npm run dev
```

Vite показывает адрес в сети: его можно открыть с телефона, подключённого к тому же Wi-Fi.

## Персонализация

Все тексты и детали события находятся в `src/config.js`. Пока не указаны исполнитель, место, время, месяц и год, сайт не отображает вымышленные детали.

Оба загруженных видео уже подключены. Серия 1 — история знакомства, серия 2 — приглашение после игры. Мобильные копии находятся в `public/videos/`:

```js
meetingVideo: '/videos/our-story.mp4',
invitationVideo: '/videos/your-invitation.mp4',
```

Рекомендуемый формат: MP4 (H.264, AAC), сжатый для мобильного интернета. Видеоплеер поддерживает вертикальные и горизонтальные ролики, `playsInline` и штатные controls. До подключения видео показывается оформленная заглушка. При ошибке загрузки можно повторить попытку.

Оригиналы сохранены локально в `source-videos/` и в отдельной ветке GitHub `original-videos`. В основной ветке и опубликованном сайте лежат облегчённые копии: примерно 8,3 и 8,7 МБ вместо 43 МБ каждая. Продолжительность видео сохранена полностью.

## Сценарий

1. Интерактивная пластинка и первая глава доступны сразу.
2. Для открытия видеоприглашения и данных концерта нужно набрать 50 баллов. Одна пойманная нота — один балл. Один раунд занимает до 30 секунд; счёт сохраняется между попытками и после перезагрузки. Сохранения старой версии с простым `unlocked: true` больше не открывают приглашение.
3. Режим «Без спешки» позволяет сыграть мелодию без таймера; для открытия также нужны 50 правильных нот.
4. Счёт и ответ сохраняются в localStorage этого браузера. Кнопка ответа открывает системное меню отправки; на компьютере копирует текст. Сам по себе клик «Да» не отправляет сообщение организатору.
5. Приглашение можно скачать в SVG или сохранить через меню телефона.

Это романтический сценарий, а не механизм ограничения доступа: клиентский код не защищает видео от прямого открытия по URL.

## Музыка в игре

В `src/config.js` → `gameTrack` подключён официальный аудиофрагмент «like JENNIE» из Apple Music. Запись проигрывается по внешней ссылке только после нажатия «Давай сыграем» / «Начать мелодию». Ноты и попадания используют текущее время аудиоплеера: при буферизации дорожка замирает вместе с музыкой. Сетка конкретного фрагмента определена по аудио: 130 BPM, фаза около 230 мс. Она хранится в `src/game.js`.

Пауза, сворачивание вкладки, завершение партии и закрытие окна останавливают музыку. Выключение звука делает запись беззвучной, сохраняя ритм игры. Повторная попытка начинает фрагмент заново, но сохраняет баллы. При ошибке сети игра продолжает работать со звуками клавиш. На странице есть ссылка на источник.

Для собственного аудиофайла можно заменить `gameTrack.source` на путь из `public/audio/`; для синхронизации нового трека нужно также обновить ритмическую сетку в `src/game.js`.

## Проверка и сборка

```sh
npm test
npm run build
npm run test:e2e
```

Для браузерных тестов используется установленный Google Chrome (по умолчанию macOS) или переменная `CHROME_PATH`. Проверяются мобильная верстка, оба режима игры, пауза, открытие приглашения, сохранение прогресса и модальные окна. Собранный статический сайт находится в `dist/`.
